# Baymax

Baymax is a clickable admin dashboard wireframe for an AI project kickoff assistant in Microsoft Teams.

The prototype turns the attached project proposal into a dashboard concept for:

- UX/UI designer-first intake and assignments
- project and bot health tracking
- Teams kickoff transcript review
- Baymax question markers and team-requested prompts
- project team capability and feasibility review
- reports and generated visual assets grouped by team member
- admin controls for bot settings, Teams access, templates, and review flow

The interface follows the `GurneyK/Design-library` React/Tailwind style: light SaaS surfaces, Habibi token colors, lucide icons, compact cards, visible review states, and calm internal-tool density.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The Vite base path is set to `/Baymax/` for GitHub Pages.
